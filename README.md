# NedomIQ - AI-powered Fitness Website

NedomIQ is a fitness website designed using HTML and CSS. This project serves as an example of how a fitness platform powered by AI could look like. It demonstrates a clean, user-friendly interface for a potential future AI fitness website.

## Technologies Used
- HTML
- CSS

## How to Use
1. Download or clone the repository to your local machine.
2. Open `index.html` in your web browser to view the webpage.
